### 《青春病》

#### 创作主题与动机

**动机母题**

**“告别青春”的誓言与“重返青春”的本能之间的无限拉锯**。这首歌的核心张力，不在于“青春多么美好”，而在于**你越是试图割断它，它越是在你体内复发**。开篇“青春の病に侵され / 儚いものばかり求めて”（被青春病所侵噬 / 往往追求虚无缥缈的事物）是一种诊断，但“ヤメた あんなことあの日でもうヤメた / と思ってた でも違った”（放弃了，那种事那天就已经放弃了 / 我曾这么以为，但是我错了）才是整首歌真正的起点——**你以为你已经痊愈了，但你错了**。“青春はどどめ色”（青春是淤青色）是这首歌最核心的意象——不是明亮的、闪耀的颜色，是淤青的、暗紫色的、身体被撞伤后留下的痕迹。藤井风在专辑Listening Party中谈到：“乗り越えたと思ったのに、またかかってしまう青春病は、こんなふうに忘れた頃にやってくるのかもしれない”（以为已经跨越了，却又再次患上青春病，也许就是这样在快要忘记的时候再度袭来）。

**视窗叙事**

这首歌的视窗是一个**在黎明前的空荡街道上奔跑的人**。“止まることなく走り続けてきた”（我不停奔跑，毫不停歇）是身体的状态，“本当はそんな風に思いたいだけだった”（其实只是想要那么认为罢了）是内心的真相——你不是真的在奔跑，你只是**想要相信自己还在奔跑**。“ちょっと進んでまたちょっと下がっては / 気付けばもう暗い空”（稍微前进，又后退几步 / 回过神之后发现天色已暗）是这个视窗的核心画面：你一直在移动，但你的位置几乎没有变化，而时间已经过去了。到了第三段，“無常の水面が波立てば / ため息混じりの朝焼けが”（当变化无常的水面波涛汹涌 / 早霞掺杂着叹息）——视窗从“暗い空”来到了“朝焼け”，天亮了，但天亮并没有带来解脱，只是换了一种光来照见同样的困境。

**情绪势能**

这首歌的能量是**从“否定青春的决绝”到“被本能拖回”的循环，再到“承认无法根除”的疲惫收束**。开篇的能量是**向下的、否定性的**——“青春にサヨナラを”（向青春告别吧），像一个人在对自己下命令。但“でも違った / 僕は自分が思うほど強くはなかった”（但是我错了 / 我并没有自己想的那么坚强）立刻把这个命令推翻，能量从“决绝”坠入了“自我怀疑”。“君の声が 君の声が / 頭かすめては焦る”（你的声音、你的声音 / 在脑海掠过，使我焦躁不已）是能量的第一次上浮——不是主动的，是**被动的、被声音拽起来的**。副歌之后，“どこへ向かって走り続けんだっけ”（我该朝向何处跑来着？）是全曲能量的最低点——奔跑还在继续，但方向已经丢失了。而最后“青春のきらめきの中に / 永遠の光を見ないで”（在青春的光辉中 / 别去注视永恒的光芒）是能量的最终落点——**不是“放弃青春”，是“在青春中不要寻找永恒”**。能量从“告别”的决绝，经过“复发”的拉扯，最终停在了“承认青春短暂，但不再试图割断它”的平静上。

#### 歌曲风格与同类型参考

**风格定位**

这首歌是一首**City Pop / J-POP**风格的作品，融合了**Funk、Jazz、R&B**等黑人音乐元素。编曲由Yaffle操刀，用**夏日感十足的合成器与钢琴line**勾勒出明亮的乐曲色彩，前奏带有**环境人声采样**，尾奏以**电吉他**收束。这首歌与同日发行的《へでもねーよ》形成了鲜明对照——后者是激进的摇滚，前者是“爽やかなポップソング”（清爽的流行歌）。旋律结构上，主歌被划分为三段，每段都由复数段的**循环乐句**构成，节奏变化丰富；副歌旋律相对平易，但在第二段副歌前出现了一个**突然的降调**，并衔接了一段全新旋律，制造出“意料之外”的听觉惊喜。整首歌时长5分21秒，在藤井风的作品中属于篇幅较长的作品。

**同风格歌曲参考**

- **藤井風《きらり》**：同样带有City Pop/Funk的清爽律动，同样在“向前走”的主题中嵌入自我审视，但《きらり》的“闪耀”是轻盈的，而《青春病》的“淤青”是沉重的。
- **藤井風《へでもねーよ》**：同日发行的姊妹作，同样是“摆脱内在束缚”的主题，但《へでもねーよ》向外投射攻击，《青春病》向内承受复发。
- **Official髭男dism《Pretender》**：同样描写“明知不该却无法抽身”的情感困境，同样在副歌处用高亢的旋律制造“承认自己可悲”的释放感。

**歌词手法小结**：《青春病》的歌词是一个**以“告别青春的誓言”为起点、以“承认无法告别”为终点的完整反转**。全曲最核心的手法，在于**将“青春”从一种值得歌颂的状态，重新定义为一种“疾病”**——“青春病”不是隐喻，是一种**真实的、会复发的、无法根治的病**。“どどめ色”（淤青色）这个意象贯穿全曲，它把青春从“闪耀的”变成了“被撞伤的”——青春不是主动选择的，是**被撞上的**。而“止まることなく走り続けてきた / 本当はそんな風に思いたいだけだった”这两句，将“奔跑”这个动作从“前进”重新定义为“想要相信自己还在前进”。MV导演山田智和谈到这首歌的创作意图时说：“このMVは、過去を描いているようで、いまを生きている人に向けて、『それでいいんだぜ』って言いたかった”（这个MV看似在描绘过去，其实是想对活在当下的人说“这样也可以的”）。整首歌的力量，不在于“告别了青春”，而在于**承认了告别是不可能的，然后依然选择继续跑**。
