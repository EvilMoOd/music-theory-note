### 想表达的主题故事与情绪

- **主题**：对“**平凡与俗气**”的接纳与自嘲。谈感情的事，写爱情的歌，总很难避开那些爱得死去活来、痛得撕心裂肺的俗套话语。这首歌的创作出发点就是“想写一首让大家有共鸣可以跟着唱的情歌”，用不夸张、不刻意的忠实陈述手法，来呈现一个人在爱情与生活的双重压力下，如何面对自己的“平庸”与“俗气”。

- **故事**：这首歌没有具体的叙事线，更像是一个深夜的自我剖白。一个人坐在那里，回顾自己在感情中的笨拙与逃避（“感情处理得都很难堪”），回顾自己在生活中为了生存而变得“变坏变混蛋”，回顾自己在爱情里“创造好幸福，原来是一个人孤独”，最后承认“不爱了是为身心健康”——整个过程，就是一个从“逃避”到“自省”再到“确认孤独”的心理轨迹。

- **情绪**：**克制的悲伤与清醒的自省**。它不是撕心裂肺的控诉，而是一个人在深夜对自己说的那些话：“怕痛怕不安”、“有时也想找个伴分摊”、“现在醒悟，现在这样哭”。李荣浩用一种口语化的、近乎聊天的方式，将一个人在爱情与生活双重压力下的复杂心境唱了出来。

### 歌曲风格与同类型参考

- **风格定位**：以**流行乐为基底，融入了弦乐与英式吉他元素的抒情作品**。编曲上，弦乐演奏纷繁纯粹，李荣浩的唱法也呈现出层次感，声音与演奏之间不是互相抢夺听觉重心，而是共同协调、保持作品的完整性与平衡性。前奏用电吉他弹奏带有忧郁色彩的分解和弦，副歌部分加入弦乐提升张力，整体营造出一种“**平凡中见真章**”的聆听体验。

- **同风格歌曲参考**：
  - **李荣浩 - 《不搭》**：同专辑中同样用平实的语言写爱情中“不搭”的无奈，情感表达克制而贴近生活。
  - **李荣浩 - 《老街》**：同样用口语化的叙述和舒缓的旋律表达怀旧与自省，在编曲和情绪上有一脉相承之处。
  - **李宗盛 - 《给自己的歌》**：在“用最平凡的语言写最深刻的自省”这一点上，有精神上的共鸣。

### 曲式结构

Intro - A1 - A2 - B - Inter1 - A3 - B - Inter2 - B - Outro

### 逐句歌词解析

| 歌词段落  | 逐句解析                                                                                                  | 手法与情绪                                                                                                                                                                                                                                                                                                                                                                                                                               |
| :-------- | :-------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **主歌1** | **到现在我还乳臭未干 / 感情处理的都很难堪 / 总会纠结 感动 欣喜若欢 / 怕痛怕不安 / 最后答案确定为 不管**   | **自我定位与逃避**：开篇就以一种极度坦诚的姿态自嘲。“乳臭未干”不是生理上的，而是情感上的不成熟——“都很难堪”是自我评价，“纠结、感动、欣喜若欢”是情感丰富的证明，“怕痛怕不安”则是逃避的根源。而“最后答案确定为不管”，是一种**自我保护式的放弃**，因为处理不了，索性不去面对。“不管”既是答案，也是借口。                                                                                                                                     |
| **主歌2** | **过去我确实不怎么样 / 现在也没有多好多强 / 有时为了生活性格变差 / 变坏变混蛋 / 有时也想找个伴 分摊**     | **对“变差”的坦诚**：延续了主歌1的自省，但不只停留在情感，扩展到了整个“生活”。为了活着，性格被磨得“变坏变混蛋”——这是一种清醒的自我批判。最后一句“也想找个伴分摊”是全曲的第一个转折点，**它暴露了渴望陪伴的本能，与前一句的“混蛋”形成了矛盾：既觉得自己不值得被爱，又渴望有人能分担这份“差”。**                                                                                                                                            |
| **副歌1** | **唱情歌落俗 说爱又太苦 / 想表达态度 又搞的你要退出 / 创造好幸福 原来是一个人孤独 / 现在醒悟 现在这样哭** | **全曲题眼**：“唱情歌落俗”——**承认自己的表达方式本身就是俗套的**。“说爱又太苦”——想表达爱，说出口又觉得苦涩与沉重。“想表达态度”指的是试图经营关系、创造幸福，“又搞的你要退出”则指向了失败的结果。“创造好幸福，原来是一个人孤独”是副歌最核心的一句——**本以为两个人在一起是为了对抗孤独，结果到头来，你依然是孤独的**。最后落在“现在醒悟，现在这样哭”——连哭都是“现在才哭”，说明情绪一直压着，直到此刻才释放。                               |
| **主歌3** | **现在爱看下午的太阳 / 开始考虑还能活多长 / 有些废话还是要和你讲 / 讲完自己扛 / 不爱了是为身心健康**      | **心态的转变**：从关注“感情”转向关注“生命”。“爱看下午的太阳”是一种对日常的重新感知，“开始考虑还能活多长”则是意识到生命有限。“有些废话还是要和你讲”很有意思——**明知道是废话，明知道对方可能不想听，但还是想说**。而“讲完自己扛”揭示了讲述者并不期待对方回应，只是需要说出来。“不爱了是为身心健康”则是一种带着自嘲的结论：不爱你了，不是因为不爱了，而是为了自己的“身心健康”——**把“分手”包装成一种“养生”行为，这是全歌最黑色幽默的一句。** |
| **副歌2** | **唱情歌落俗 说爱又太苦 / 想表达态度 又搞的你要退出 / 创造好幸福 原来是一个人孤独 / 现在醒悟 现在这样哭** | **重复中的确认**：副歌完全重复，但此时经过主歌3的“开始考虑还能活多长”和“不爱了是为身心健康”，副歌的情感分量更重了。**第一次副歌是“醒悟”，第二次副歌是“确认”——同样的话说第二遍，就不再是发现，而是接受了。**                                                                                                                                                                                                                              |

**歌词手法小结**：《落俗》的歌词是一个**从“逃避”到“自省”再到“确认孤独”的完整弧线**。它用极度口语化的、不押韵的短句，营造出一种“深夜自白”的私密感。全歌最核心的手法在于**用“俗”这个字完成了双重自嘲**——既承认自己在用“唱情歌”这种俗套的方式表达，也承认自己面对感情时的犹豫、逃避、“变混蛋”都是“俗人”会做的事。它不试图给出任何答案，只是诚实地呈现了一个在爱情与生活双重压力下自我拉扯的普通人，而**这种“平庸的诚实”，正是这首歌最打动人的地方**。就像李荣浩自己说的：“歌和生活是一个道理，是什么样就是什么样。”
