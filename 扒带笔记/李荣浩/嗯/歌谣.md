### 《歌谣》

#### 创作主题与动机

**动机母题**

远行与归乡。《歌谣》的核心张力不在于“乡愁”本身，而在于**乡愁如何成为一种可以随身携带的力量**。“站台渐渐远去”是离开的动作，“家乡那儿的歌谣”是带在身上的东西。你离家乡越来越远，但歌谣一直跟着你。它不是回忆，是工具——在你“感到沮丧”的时候，你可以主动“唱起歌谣”，用它来“看到原来的模样”。整首歌的母题就在这个动作上：**乡愁不是被动的思念，是可以主动调用的心理资源**。

李荣浩刚开始离乡背井在外打拼时，曾饱尝对家乡的思念之情，有时候会忽然哼起小时候爸妈最爱哼的一首歌谣，或是想起爷爷奶奶曾说过的故事，这些都给了他最温暖的慰藉，因此有感而发写下了这首歌。歌谣对李荣浩来说是一种“依靠”和“好”——它不是用来听的，是用来唱的。

**视窗叙事**

这首歌的视窗是一列**正在驶离家乡的火车窗边**。“站台渐渐远去”是第一眼看到的画面——你在车里，站台在后退。“刚好下起了小雨”是窗外的天气，也是情绪的底色。“六点半的火车上/一口没喝的豆浆”是窗内的细节——你坐在座位上，面前放着一杯还没来得及喝的豆浆。前半段所有画面都在火车上完成：窗外的站台、窗外的雨、窗内的豆浆、窗内的行李箱。后半段视窗从火车滑向了“努力打拼的日子”——不再是具体的场景，而是一段被压缩的时间。最后“每一次我感到沮丧就唱起歌谣”把视窗从“看”切换到了“唱”——不再是坐在车里看窗外，是闭上眼睛，开口唱。汽笛声和火车经过的声音作为开头和结尾，为整首歌提供了画面感极强的代入感。

**情绪势能**

这首歌的能量是从**离开时的低沉，到副歌的扬起，再到结尾的升华**的三段式弧线。前奏的汽笛声和火车声奠定了离别与远行的基调。主歌“站台渐渐远去”“爸妈嘱咐几句”“行李箱牵挂的重量”是叙述式的、平的——像坐在火车上看着窗外，情绪没有起伏，只是安静地记录。副歌“家乡那儿的歌谣”是能量第一次往上走，但走得不急——不是呐喊，是像一个人在哼唱。旋律上口，歌者口吻亲切，接受起来很容易。副歌中有一个小二度不稳定音程，解决之后让歌曲的层次丰富了很多。结尾处升了一个调，情绪变得更加激昂。最后一次“这样就会回到我来的地方”把能量从“看到原来的模样”推到了“回到我来的地方”——从看见，到回去。

#### 歌曲风格与同类型参考

**风格定位**

《歌谣》是一首以**吉他扫弦和鼓**为主要编曲骨架的流行歌曲。李荣浩独立完成词曲、编曲、吉他、贝斯、和声编写及制作。鼓手由荒井十一担任。歌曲时长5分25秒。整首歌的听觉质感是“淳朴、真挚”的，属于李荣浩的常规风格。鼓点的敲打像是敲在心中，副歌前的空拍之后鼓和吉他同时加进，有一种“漂浮的小船找到依靠的舒适感”。这首歌被形容为“写的是思念家乡的温柔乡愁”，它的悦耳度、上口度、流行性都很符合大众标准。

**同风格歌曲参考**

- **李荣浩《爸爸妈妈》**：同属专辑《嗯》中的温情路线作品，同样以平实的叙述和舒缓的旋律写亲情与乡情。
- **李荣浩《老街》**：同样写“回不去”的故乡与时光，同样以具体的物象（照片/热汤面、站台/火车/豆浆）作为记忆的载体。
- **李荣浩《二三十》**：同样写“正在流逝的时光”与“回头看路程”的感怀，同样用白描手法拼凑出平凡生活的质感。

#### 曲式结构

Intro - A1 - A2 - B(2) - C1 - C2 - Inter - A2 - B - C1 - C2 - C2(4) - Outro

#### 逐句歌词解析

| :--------------- | :------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **主歌1**        | 站台渐渐远去 / 刚好下起了小雨 / 爸妈嘱咐几句 / 要好好照顾自己 / 六点半的火车上 / 一口没喝的豆浆 / 行李箱牵挂的重量   | 开篇是一连串出发时的具体画面。“站台渐渐远去”是离开的动作——你在车里，站台在后退。“刚好下起了小雨”是天气，也是离别的底色。“爸妈嘱咐几句”是送行时最常见的场景，“要好好照顾自己”是父母最朴素的话。“六点半的火车上/一口没喝的豆浆”是一个极其具体的细节——你坐在早班火车上，面前放着一杯还没来得及喝的豆浆。“行李箱牵挂的重量”把“牵挂”这个抽象的词放在了行李箱上——行李是重的，牵挂也是重的。 |
| **主歌2**        | 经过了一段段 / 努力打拼的日子 / 跌倒过很多次 / 没有放弃这回事 / 小时候大人爱讲 / 外面的天有多大 / 有一天我也要去闯   | “经过了一段段”是一个时间的跳跃——从火车上的那个早晨，跳到了“努力打拼的日子”。“跌倒过很多次/没有放弃这回事”是这段日子的总结——摔过，但没停。“小时候大人爱讲/外面的天有多大”是出发的理由——小时候听大人说外面很大，于是想去看。“有一天我也要去闯”是那个“有一天”终于到了——你坐在了那列火车上。                                                                                              |
| **副歌**         | 流泪和流汗我不怕 / 家乡那儿的歌谣 / 对我来讲是种依靠 / 陪伴我多少次艰难 / 彩虹多绚烂 绚烂的多平凡 / 画面里那样的好看 | “流泪和流汗我不怕”是决心——身体上的苦可以承受。“家乡那儿的歌谣/对我来讲是种依靠”——歌谣不是回忆，是工具，是可以主动拿出来用的东西。“陪伴我多少次艰难”说明它不是一次性的，是反复被调用的。“彩虹多绚烂/绚烂的多平凡”——彩虹是绚烂的，但“多平凡”把它拉回了地面：绚烂的东西也可以是平凡的。“画面里那样的好看”是站在此刻回看过去的自己——那个在火车上的自己，那个画面，是好看的。              |
| **副歌（重复）** | 家乡那儿的歌谣 / 对我来讲是一种好 / 是我最顽强的一角 / 每一次我感到沮丧就唱起歌谣 / 这样就会看到原来的模样           | 副歌再次出现，但做了替换：从“依靠”变成了“好”，从“陪伴我多少次艰难”变成了“是我最顽强的一角”。“顽强的一角”是一个很具体的比喻——你是由很多块拼成的，歌谣是其中“最顽强”的那一块。“每一次我感到沮丧就唱起歌谣”——“每一次”说明这不是偶然，是一个固定的动作。“这样就会看到原来的模样”——不是“想起”，是“看到”；不是过去的样子，是“原来的模样”。                                                  |
| **副歌（最终）** | 每一次我感到沮丧就唱起歌谣 / 这样就会看到原来的模样 / 这样就会回到我来的地方                                         | 最后一次副歌在结尾处多了一句“这样就会回到我来的地方”。前两次是“看到原来的模样”（视觉的、回望的），这一次是“回到我来的地方”（身体的、抵达的）。**从“看到”到“回到”，是一个质的跳跃——歌谣不只是让你想起家乡，它让你在某种程度上回到了家乡。**                                                                                                                                            |
