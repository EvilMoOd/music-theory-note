### 《裙姊》

#### 创作主题与动机

**动机母题**

传统 vs. 潮流。“裙姊”是京剧大师梅兰芳的乳名，这首歌的核心不在于复刻一段历史，而在于**把“传统”重新定义为一种“很潮”的东西**。一百多年前，梅兰芳打破京剧只重形式、缺乏情感表达的旧框，注入更充沛的情绪，本身就是一次“很潮”的革新。李荣浩并非以一个仰望者的姿态去写一首“中国风”的颂歌，而是将一个百年前的“潮流偶像”拉到现代语境中，让他和当代年轻人站在一起。歌里反复出现的“先生唱的戏 / 传统的东西 / 是一种鼓励”，就是在反复确认这个判断：传统不是遗产，是还可以继续往前走的动力。

**视窗叙事**

这首歌的视窗是**一个21世纪的音乐人，站在剧场后台，透过幕布的缝隙看向百年前的舞台**。前半段“仰着头楚歌中殉情 / 开了口醉倒百花亭”像在看戏——舞台上正在演《霸王别姬》和《贵妃醉酒》，镜头是仰视的、观众席的视角。而“巷弄的墙壁和洋车 / 灯亮着梳洗着粉墨”则把镜头拉到了后台——巷弄、洋车、粉墨，戏里戏外的边界被模糊了。到了副歌“先生唱的戏”，视窗从“看戏的人”切换到了“唱戏的人”身边——不是仰望，是并肩。“那时候那个文艺少年后来成为了神”是视窗的最终落点：从一个“文艺少年”到“神”，中间隔着的，就是“先生唱的戏”这四个字重复的那段路。

**情绪势能**

这首歌的能量是**从“看热闹”到“看门道”的上升弧线**。前半段的“楚歌中殉情”“醉倒百花亭”“挥舞宝剑”“先干为敬”是一连串戏剧画面的快速切换，能量是散的、跳动的，像在逛庙会，东看一眼西看一眼。到了“谁的惊天爱情 / 为老百姓补充了娱乐”，节奏慢下来，开始提问了——谁是那个“谁”？副歌“先生唱的戏”是能量第一次收拢，从散点的画面收束到一个人身上。后半段“艺术的派系不能分高低”“身段要有力”是能量最“正”的部分——不再是看热闹，是在讲道理了。结尾的“La la la”把能量从“讲道理”的位置轻轻松开，不继续往上推，也不往下掉，只是让它在那个高度上慢慢转完。

#### 歌曲风格与同类型参考

**风格定位**

这首歌被形容为“**中西曲风大碰撞**”——巧妙结合了**西方的嘻哈音乐（Hip Hop）** 以及**东方的民乐合奏**。编曲上既有中国古典乐器的铺陈，又有电子音乐元素的融入。有评论形容它“似中国风但也却不太浓”，不是传统意义上的“中国风”歌曲，而是用Hip Hop的节奏骨架去承载京剧的意象和唱段精神。李荣浩在MV中化上京剧传统妆容、揣摩武术身段舞剑，与9名武生对打，将歌曲的“冲突感”视觉化了。歌曲时长3分31秒。

**同风格歌曲参考**

- **李荣浩《李白》**：同样用现代的音乐语言（乡村摇滚 / Hip Hop）去包裹一个历史人物的名字，同样把“古人”当作一种精神符号来使用。
- **周杰伦《霍元甲》**：同样将Hip Hop / 摇滚与民乐 / 京剧元素结合，同样在MV中融入中国传统文化符号，在“东西合璧”的曲风路线上有相似之处。
- **王力宏《在梅边》**：同样以京剧 / 昆曲为题材，同样在歌词中融入戏曲唱段和身段描写，同样探讨传统艺术在现代语境中的位置。

#### 曲式结构

Intro - A1 - A2 - B1(2) - C1 - A3 - B2(2) - C2 - C2 - Outro(短)

| **主歌1** | 仰着头 楚歌中殉情 / 开了口 醉倒百花亭 / 爱妾 挥舞宝剑 / 剧情缠绵 刺到你的心 / 贵妃 先干为敬 / 让人好动情                    | 开篇是一连串京剧经典剧目的画面切片。“楚歌中殉情”是《霸王别姬》中虞姬自刎，“醉倒百花亭”是《贵妃醉酒》中杨玉环的醉态。“爱妾挥舞宝剑”把虞姬的“妾”的身份和“舞剑”的动作并置，“刺到你的心”既是剧情中的动作，也是对观众说的。“贵妃先干为敬”把《贵妃醉酒》中杨贵妃的饮酒动作写成了一种江湖式的敬酒——贵妃在敬你一杯。“让人好动情”是观众的反应——戏演到这儿，你已经进去了。                   |
| **主歌2** | 巷弄的 墙壁和洋车 / 灯亮着 梳洗着粉墨 / 谁的 惊天爱情 / 为老百姓 补充了娱乐 / 谁有 街头巷尾 传奇的资格 / 古今中外只有他一个 | 镜头从舞台拉到了后台和街巷。“墙壁和洋车”是民国时期的街景，“灯亮着梳洗着粉墨”是演员在上台前最后的准备——在灯下化妆。“谁的惊天爱情 / 为老百姓补充了娱乐”——“惊天爱情”是戏里的，但“补充了娱乐”是戏外的。它在问：舞台上演的悲欢离合，到底是为谁演的？“谁有街头巷尾传奇的资格 / 古今中外只有他一个”——自问自答：只有一个人配得上“传奇”这两个字。                                           |
| **副歌**  | 先生唱的戏 深厚的功底 / 用一套青衣 创一个世纪 / 先生唱的戏 现在和过去 / 传统的东西 是一种鼓励                               | 副歌从“看戏的人”视角切换到了“唱戏的人”身边。“先生”是对梅兰芳的尊称。“深厚的功底”是“台下十年功”，“用一套青衣创一个世纪”——“青衣”是京剧旦角的一种，用一套青衣就能开创一个时代。“现在和过去”把两个时间并置——先生的戏既在过去，也在现在。“传统的东西 / 是一种鼓励”——这是整首歌最核心的判断：传统不是压在身上的，是推着你往前走的。                                                      |
| **主歌3** | 免不了 英雄和情人 / 一小折 净丑末旦生 / 那时候那个文艺少年后来成为了神 / 结合 霸气灵魂 优雅的肉身 / 台下求之不得几万人      | “免不了英雄和情人”是说：戏里演来演去，无非是英雄和情人的故事。“一小折净丑末旦生”是京剧行当的罗列——净、丑、末、旦、生，五个行当。“那时候那个文艺少年后来成为了神”——梅兰芳从一个“文艺少年”到被供奉为“神”，中间隔着的就是“先生唱的戏”。“结合霸气灵魂优雅的肉身”是对梅兰芳表演风格的概括——既有力量（霸气），又有美感（优雅）。“台下求之不得几万人”是万人空巷的场面——几万人在台下看他。 |
| **主歌4** | 先生唱的戏 教我们道理 / 艺术的派系 不能分高低 / 先生唱的戏 身段要有力 / 故事的结局 泪洒过几滴                               | 副歌之后延伸出的新段落。“教我们道理”是“先生唱的戏”的第三个功能——前两次是“功底”和“世纪”，这次是“道理”。“艺术的派系不能分高低”是整首歌唯一一次直接点题——京剧和流行音乐、东方和西方、传统和现代，没有高低之分。“身段要有力”是对表演者的要求——不只是唱，身体也要有力量。“故事的结局泪洒过几滴”把视线拉回到戏的结尾——再精彩的戏，最后也是泪洒几滴。                                     |
