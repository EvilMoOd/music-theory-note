### 《嗯》

#### 创作主题与动机

**动机母题**

规训 vs. 野性。这首歌写的是“十八岁”，但不是怀念十八岁，是**回到十八岁还没被驯服的状态**。“刚走进社会 / 人得罪一堆”是野性撞上规则的第一回合——你不懂规则，你也不想懂。“拒绝一切认输 / 从来都不服”是这种野性的另一个名字：不服。整首歌的母题不在于“叛逆”本身，而在于**你还记得十八岁时那种“不服”的感觉吗？** 李荣浩认为“叛逆”不代表做坏事，而是对世界充满好奇，对自己的所求有所掌握，从而活出自己的态度。歌里反复出现的“嗯”，就是这个态度的声音化——不是反抗，是懒得跟你解释。

**视窗叙事**

这首歌的视窗是**一个正在回看自己十八岁的人，站在十八岁和现在之间的某个位置**。“刚过十八岁”在歌里反复出现，像一句不断被确认的旁白——不是“我十八岁那年”，是“刚过十八岁”，一个还没完全进入成人世界、但已经站在门口的时间点。前半段“有一种人类 / 没有兄弟姐妹 / 刚走进社会 / 人得罪一堆”像在描述一个样本——一种人类，一种刚成年的、还不懂规矩的人类。后半段“崇拜的人物 / 是个大人物 / 他上山打过鼓 / 下山打过虎”把视窗从“你”转向了“他”——那个你十八岁时崇拜的人，那个你希望成为的人。整首歌在两个位置之间切换：一个是“你”（正在十八岁的人），一个是“他”（你十八岁时想成为的人）。

**情绪势能**

这首歌的能量是**向外冲的、不压着的**。前奏被形容为“全专中最重型最刚猛的段落”，贝斯厚重，节奏重拍强烈。人声退到器乐之后，器乐重到“你以为听到了假的李荣浩”。主歌是叙述式的、带点“杀马特”画面感的，“发型里的另类 / 贫穷却有品味”像一种自我标榜，但语气里没有心虚。副歌“嗯嗯嗯嗯”是能量最集中的释放——十多个“嗯”音节组成洗脑旋律，不需要歌词，不需要解释，一个语气词就够了。整首歌的能量不往下掉，它一直在往外溢，像一个人憋了很久终于把想说的话用一个“嗯”字全部堵回去。

#### 歌曲风格与同类型参考

**风格定位**

《嗯》是一首**复古慢摇滚**作品，同时兼具**先锋与复古**的色彩。编曲上，人声被刻意退到器乐之后，**Blues味道极重的贝斯**弹奏着鼓噪，甚至带有**Trap影子**的节拍器。整首歌的听觉质感是“重型”的——厚重的贝斯、强烈的节奏、即将喷薄而出的情绪。有乐评形容这首歌“用厚重的贝斯裹挟一种玩世不恭的恣意”。它在音乐样态上“大大地玩了一把人声”，人声不再是主角，器乐才是。曲风上的大幅转型，让这首歌成为李荣浩第四张专辑《嗯》中最具突破性的作品。

**同风格歌曲参考**

- **李荣浩《快让我在雪地上撒点野》**：同样是翻唱崔健时展现的摇滚能量，同样是“不服”和“撒野”的主题。有乐评指出，这种叛逆的玩乐感在李荣浩第二张专辑的翻唱中已有体现，而《嗯》是“他已经可以只用十多个‘嗯’音节组成洗脑旋律”来独立完成表达的作品。
- **李荣浩《有理想》**：同属轻快节奏、自嘲语气讨论“理想”的歌曲，但《有理想》是“把眼前的事做好”的务实，《嗯》是“不服”的直给。
- **李荣浩《野生动物》**：同样用粗粝的编曲和“不服从”的姿态写本能与规训的对抗，在Blues Rock的能量上一脉相承。

| **主歌1**        | 有一种人类 没有兄弟姐妹 / 刚走进社会 人得罪一堆 / 发型里的另类 贫穷却有品味 / 谁也学不会       | “有一种人类”是一个“物种观察”式的开场——把自己从“正常人”里摘了出来。“没有兄弟姐妹”是独生子女一代的普遍状态，也是“没有人教你怎么做人”的潜台词。“刚走进社会/人得罪一堆”是野性撞上规则的第一回合——你不懂规则，你也不想懂。“发型里的另类/贫穷却有品味”是外在的标记——你从外表上就已经和“他们”不一样了。“谁也学不会”是对“学”这个动作的拒绝——不是学不会，是不想学。                               |
| **主歌2**        | 不喜欢纹身龙凤系列 / 为一个爱的人去流血 / 也许高尚的人不理解 / 怀旧热泪和重口味 / 少一个都不对 | “不喜欢纹身龙凤系列”是一个拒绝——纹身龙凤是“江湖气”的符号，但“我”不要那种被定义的“江湖”。“为一个爱的人去流血”是唯一一次正面描述“爱”——不是甜言蜜语，是“流血”，是身体性的、有代价的。“也许高尚的人不理解”是一个预判——你知道有人会觉得你low，但你不在乎。“怀旧热泪和重口味/少一个都不对”是自我画像的两个面：一边是怀旧的、会流泪的，一边是重口味的、不精致的。两者加在一起，才是完整的“我”。 |
| **副歌**         | 嗯嗯嗯嗯 / 刚过十八岁 / 嗯嗯嗯嗯 / 所以你不配                                                  | “嗯”是整首歌的题眼——一个语气词，不需要翻译。“刚过十八岁”是时间标记——不是“十八岁那年”，是“刚过”，还热着的。“所以你不配”是整首歌最直的一句——不配什么？不配评价我，不配理解我，不配教我做人。                                                                                                                                                                                               |
| **主歌3**        | 崇拜的人物 是个大人物 / 他上山打过鼓 下山打过虎 / 最不害怕吃苦 / 拒绝一切认输 / 从来都不服     | 视窗从“我”切换到了“他”——那个你十八岁时崇拜的人。“上山打过鼓/下山打过虎”是江湖式的夸张——不是真的打鼓打虎，是“什么都干过”的象征。“最不害怕吃苦/拒绝一切认输/从来都不服”是三种品质：能扛、不认、不服。这三样加在一起，就是十八岁的你希望自己成为的样子。                                                                                                                                    |
| **副歌（重复）** | 嗯嗯嗯嗯 / 刚过十八岁 / 嗯嗯嗯嗯 / 所以你不配 / 嗯嗯嗯嗯 / 刚过十八岁 / 嗯嗯嗯嗯 / 所以我不配  | 副歌在后半段多了一句“所以我不配”——前半段是对别人说的“你不配”，后半段是对自己说的“我不配”。**从“你们不配评价我”到“我也不配成为那个大人物”**，是一个微妙的下坠。但“我不配”在这里不是认输，是一种清醒：我知道我还没成为我想成为的人，但我还在路上。                                                                                                                                         |
