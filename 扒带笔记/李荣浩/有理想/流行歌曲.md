### 《流行歌曲》

#### 创作主题与动机

**动机母题**

“对不起”与“谢谢你”——一段感情结束后，剩下的两种措辞。《流行歌曲》的母题不在于爱情本身，而在于**记忆如何被封装成一种可被传唱的形式**。歌里反复出现的“写成流行歌曲”是一句自我指涉——这首歌正在做的，就是把一段已经结束的感情、一个已经消失的人、一种已经无法挽回的状态，变成一首可以被反复播放的歌。而“人人都有几句/流行歌曲”则把这种封装推向了普遍性——**每个人的记忆里都有几段被歌曲锚定的情感，你的故事和我的故事，最终都汇入了同一套旋律和同一套措辞**。“对不起”是结束时的告别，“谢谢你”是回忆时的释然，两句加在一起，就是一首流行歌曲的全部内容。

**视窗叙事**

这首歌的视窗是一个**回望童年和少年时期的、带着距离感的审视位置**。“严格来说/是小时候”像一个免责声明——接下来说的一切都发生在“小时候”，所以不必太当真，也不必太追究。这个位置让叙述者可以站在现在，看过去的自己“口头上是男女朋友”、“送你到你家巷口”、“什么都没说”——那些模糊的、不确定的、甚至可能从未被确认过的关系，都被“小时候”三个字轻轻盖住。而“后来就很少联系/就成了结局”是这段关系唯一的推进——它没有戏剧性的分手，只是慢慢地、自然地消失了。

**情绪势能**

这首歌的能量是**循环式的、自我消解的**。“我听说对不起/也算是个约定/能不能在一起/都没关系”——开篇四句就把整首歌的调性定在了“都没关系”上。一段感情可以在一起，也可以不在一起，结局已经不重要了，重要的是它被写成了歌。主歌叙述童年往事时，能量是平的、叙述式的，像一个在翻旧照片的人，语气里没有波澜。副歌“写成流行歌曲”是唯一一次往上走，但它不是情绪的释放，更像一种自我指认——**“哦，原来这件事最后变成了这首歌”**。结尾“我听说了消息/嫁的人好爱你/人人都有几句/流行歌曲”把能量压到了最低——那个人已经嫁给了别人，而“我”只是在某首歌里听说她过得很好。歌可以循环播放，但人生不会重来。

#### 歌曲风格与同类型参考

**风格定位**

《流行歌曲》延续了李荣浩标志性的**极简主义编曲风格**，通过钢琴与弦乐的复合编排，构建出兼具叙事感与流行度的音乐框架。李荣浩最初用Bass反复修改了整首歌的编曲，最终版本以充满复古感的电吉他与打击编制呈现。整首歌在人声、钢琴与弦乐之间保持了良好的平衡，没有过度堆砌，将情感藏在了旋律的留白之中。专辑封面采用黑白极简设计，与歌曲“在浮夸世界里保持低调”的创作理念形成呼应。

**同风格歌曲参考**

- **李荣浩《老街》**：同样用平实的叙述和舒缓的旋律写“回不去”的时光与情感，同样以具体的物象（照片、热汤面/“你家巷口”）作为记忆的载体。
- **李荣浩《爸爸妈妈》**：同专辑作品，同样以“回头看”的姿态写“已经过去的日子”，同样用口语化的短句和低能量的叙述构建私密的聆听空间。
- **李荣浩《二三十》**：同样写“正在流逝的年华”，同样以“回头看了看路程”的姿态做时间上的回望。

#### 曲式结构

B1 - Intro - A1 - A2 - B1 - B2 - ReIntro - A1 - A2 - B1 - B2 - B3 - Outro

#### 逐句歌词解析

| 歌词段落          | 逐句解析                                                                            | 手法与情绪                                                                                                                                                                                                                                                                                                                                         |
| :---------------- | :---------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **开篇**          | 我听说对不起 / 也算是个约定 / 能不能在一起 / 都没关系                               | 开篇四句是整首歌的“歌眼”。“对不起”是分手时最常听到的词，“也算是个约定”把它重新定义了——不是道歉，不是结束，而是一种默认的共识。“能不能在一起/都没关系”是整首歌情绪基调的定调：结果已经不重要了，重要的是它曾经发生过。                                                                                                                              |
| **主歌1**         | 严格来说 / 是小时候 / 口头上是男女朋友 / 送你到你家巷口 / 什么都没说 / 是因为牵着手 | “严格来说”是一个带着距离感的开头，像是在说“我要开始讲一段不太确定的事了”。“小时候”把一切都罩上了一层模糊的滤镜——那时候的关系是“口头上”的，没有正式确认，也没有正式结束。“送你到你家巷口/什么都没说/是因为牵着手”是一个极其具体的画面——两个人沉默地走了一段路，手牵着手，但什么话都没说。**沉默不是因为没话说，是因为手已经牵着，话就不需要说了。** |
| **主歌2**         | 想不起来什么原因 / 很常见的各奔东西 / 后来就很少联系 / 就成了结局 / 写成流行歌曲    | “想不起来什么原因”是最诚实的一句——很多关系的结束并没有一个明确的原因。“很常见的各奔东西”把这段关系放进了普遍性的框架里：不是特例，不是悲剧，是每天都在发生的事。“后来就很少联系/就成了结局”——没有争吵，没有告别，只是慢慢地不联系了。而“写成流行歌曲”是整首歌的自我指认：**这段无疾而终的感情，最终变成了一首歌**。                                |
| **副歌**          | 我听说谢谢你 / 会让泪流不停 / 不适合的年纪 / 都给彼此鼓励                           | 副歌从“对不起”转向了“谢谢你”——从结束时的措辞转向了回忆时的措辞。“会让泪流不停”是唯一一次正面承认情绪的存在，但紧接着“不适合的年纪/都给彼此鼓励”又把情绪收了回去——那时候太年轻了，能给彼此的只有鼓励。                                                                                                                                              |
| **主歌/副歌重复** | （重复主歌1、主歌2、副歌）                                                          | 歌曲中段完整重复了前面的段落，重复本身就像在说：这段记忆就是这样，翻来覆去地回想，也找不到更多细节了。                                                                                                                                                                                                                                             |
| **尾声**          | 我听说了消息 / 嫁的人好爱你 / 人人都有几句 / 流行歌曲                               | “我听说了消息”是多年后偶然得知的对方的近况。“嫁的人好爱你”是一个简洁的、完整的结局——她过得很好，嫁给了一个很爱她的人。而“人人都有几句/流行歌曲”是整首歌的最终落点：**不只是“我”的故事被写成了歌，每个人的故事里都有几句可以被唱出来的歌词**。这首歌写的是“我”的故事，但“人人都有几句”把它打开了一个口子——你也可以把你的故事放进去。                |
