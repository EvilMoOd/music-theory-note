# 模特

### 1. 想表达的主题故事与情绪

- **核心主题**：这首歌以“橱窗里的模特”作为核心隐喻，探讨**现代人在消费主义社会中的物化、压抑与觉醒**。歌词中“穿华丽的服装，为原始的渴望而站着”、“用完美的表情，为脆弱的城市而撑着”，描摹的不仅是T台上的模特，更是每一个为了生存而戴上面具、在职场和生活中扮演着“完美角色”的我们。它源自李荣浩对生活的观察，灵感来自黑人音乐，也融入了对电影和人物的思考。更深一层，它也折射出创作者本人从幕后蛰伏十年，凭借这张为自己制作的专辑一鸣惊人的心路历程。

- **主导情绪**：歌曲的情绪是**复杂而充满张力的**。表面是一种**克制、冷漠甚至慵懒的叙述**，仿佛已经习惯了这种“模特”般的生存状态。但内核却涌动着一股**压抑不住的反抗与渴望**，尤其是在副歌部分，“谁说世界早已没有选择”、“至少证明我们还活着”，这种对“活着”的强调，是对麻木现状最温柔也最有力的反击。

### 2. 歌曲风格与同类型参考

- **风格定位**：这首歌的音乐风格常被描述为融合了**灵魂乐（Soul）、蓝调（Blues）和爵士（Jazz）元素的流行乐**，带有鲜明的**都市感**和“欧美范儿”。它弱化了传统黑人音乐中强烈的节奏与和声，更侧重于旋律的美化，让转音和颤音的处理更柔和，因此听起来既有格调，又非常贴合华语听众的耳朵。整首歌的编曲简洁，营造出一种仿佛在小型Live现场的私密感和真实感。

- **同风格歌曲参考**：
  - **李荣浩 - 《李白》**：同样出自这张专辑，虽然节奏更偏乡村摇滚，但在那种慵懒、洒脱又带点自嘲的气质上一脉相承。
  - **方大同 - 《Love Song》**：在华语乐坛中，同样擅长将灵魂乐、R&B与流行旋律完美结合的典范，律动感强，听感流畅。
  - **John Mayer - 《Gravity》**：李荣浩的音乐风格常被指受到John Mayer的影响。这首歌在那种克制而深情的吉他编曲和略带沙哑的唱腔上，能找到一些精神共鸣。

### 3. 曲式结构

Intro - A1 - B1 - C - A2 - B2 - C - Inter - C（旋律变化） - Outro

### 4. 逐句歌词解析

| 歌词段落    | 逐句解析                                                                                                                               | 手法与情绪                                                                                                                                                                                                                                                                                 |
| :---------- | :------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **主歌1**   | **穿华丽的服装 为原始的渴望而站着 / 用完美的表情 为脆弱的城市而撑着**                                                                  | **对立并置**：开篇第一句就把“华丽的服装”（外在、伪装、社会角色）和“原始的渴望”（内在、本能、真实自我）并置，直接点明了全曲的核心矛盾。“为脆弱的城市而撑着”则将个人的伪装升华为都市生存的普遍状态——“撑着”写出了疲惫与不得已。                                                               |
|             | **我冷漠的接受 你焦急的等待也困着 / 像无数生存在橱窗里的模特**                                                                         | **困境的确认**：“冷漠的接受”是“我”对现状的态度，而“你焦急的等待也困着”——“你”可能是旁观者、爱人，或内心的另一个自己，同样被困在这个“模特”的处境里。最后用“橱窗里的模特”收束全段，完成了“都市人=橱窗模特”的核心隐喻。                                                                        |
| **预副歌1** | **除了灯以外 我还能看见什么 / 除了光以外 我还能要求什么 / 除了你以外 还能倚赖哪一个**                                                  | **排比与叩问**：一连串“除了...还能...”的排比，是内心迷茫的自我拷问。“灯”代表外在的、可见的光鲜，“光”是更抽象的希望，“你”是情感联结。从物质到精神，逐层递进，揭示了内心的匮乏——除了这些，什么也看不见、要求不了、倚赖不到。                                                                 |
|             | **在千里以外 在呼喊的是什么 / 在百年以后 想回忆的是什么 / 在离开以前 能否再见那一刻**                                                  | **时空的追问**：从“千里以外”（空间）到“百年以后”（时间）再到“离开以前”（生死），三个追问将个人的困境扩展到了时空的维度。它在问：远方有什么在呼唤？这一生会留下什么回忆？离开前还能不能再见？——**这些追问本身，就是“活着”的证明。**                                                         |
| **副歌**    | **记得 你的眼睛将会亮着 / 我的手臂将会挥着 / 谁说世界早已没有选择**                                                                    | **核心宣言**：进入副歌，能量首次释放。“眼睛亮着”象征希望与觉醒，“手臂挥着”象征行动与挣脱。最后一句“谁说世界早已没有选择”是全曲最有力的一句反问——它直接反驳了主歌中那种“只能接受”的无力感，是全曲反抗情绪的最高点。                                                                         |
|             | **趁着 我会喜怒你会哀乐 / 唱几分钟情歌 / 没什么 至少证明我们还活着**                                                                   | **自我确认**：“我会喜怒你会哀乐”是真实情感的证明——“我”还能喜怒，“你”还会哀乐，说明我们还没有完全麻木。“唱几分钟情歌”是具体的行动，而“至少证明我们还活着”是整首歌的落点：**活着本身，就是反抗的起点。**                                                                                     |
| **主歌2**   | **像单纯的蝴蝶 为玫瑰的甜美而飞着 / 像顽皮的小猫 为明天的好奇而睡着**                                                                  | **意象的转换**：相比主歌1的“华丽的服装”和“完美的表情”，这里用了“蝴蝶”和“小猫”两个更轻盈、更自由的意象。它们“为甜美而飞”“为好奇而睡”，是本能驱动的、不受束缚的生命状态——这是对自由最直接的想象。                                                                                            |
|             | **是混乱的时代 是透明的监狱也觉得 / 是不能继续在橱窗里做模特**                                                                         | **从觉知到行动**：“混乱的时代”承认外部环境的无序，“透明的监狱”则是对“橱窗”的重新定义——它看似透明、看似自由，实则是监狱。最后一句“是不能继续在橱窗里做模特”是全曲的转折点：**从“像无数生存在橱窗里的模特”到“不能继续在橱窗里做模特”——从描述现状到拒绝现状，完成了从觉知到行动的转变。**     |
| **预副歌2** | **除了风以外 我还能听到什么 / 除了尘以外 我还能拒绝什么 / 除了你以外 还能倚赖哪一个**                                                  | **呼应桥段1**：与之前的“灯/光/你”形成对照——“灯”换成了“风”，“光”换成了“尘”。“风”是自然的声音，“尘”是现实的尘埃。从“看见什么”到“听到什么”，从“要求什么”到“拒绝什么”——**从被动接受到主动拒绝，是心态上的升级。** 最后一句“除了你以外还能倚赖哪一个”与前段完全一致，说明“你”是唯一不变的锚点。 |
| **副歌2**   | **记得 你的眼睛将会亮着 / 我的手臂将会挥着 / 谁说世界早已没有选择 / 趁着 我会喜怒你会哀乐 / 唱几分钟情歌 / 没什么 至少证明我们还活着** | **重复与强化**：副歌完全重复，但此时经过主歌2“是不能继续”的宣言，能量比第一次更足。重复本身也是一种确认——**第一次是“相信”，第二次是“笃定”。**                                                                                                                                              |

**歌词手法小结**：《模特》的歌词是一个从“**描述困境**”到“**追问意义**”再到“**选择反抗**”的完整弧线。主歌1用“橱窗里的模特”建立核心隐喻；桥段1用时空追问将个人的困境升华为普遍的生存命题；副歌用“谁说世界早已没有选择”给出第一次反抗；主歌2用“蝴蝶”和“小猫”的意象描绘自由的想象，并以“是不能继续在橱窗里做模特”完成从被动到主动的转变；桥段2将“看见/要求”换成“听到/拒绝”，标志着心态的升级。整首歌的歌词，**就是一个人从“在橱窗里站着”到“决定走出橱窗”的心理全过程**。
