### 《乐团》

#### 创作主题与动机

**动机母题**

闷热 vs. 傲骨。《乐团》描绘的是无数地下乐队和音乐人曾经历过，甚至正在经历的困境——在低预算、没空调、闷热的排练室里，一遍遍磨合着“以为会红会火”的歌。其核心张力不在于“梦想终会实现”，而在于**即使在无人问津的闷热中，音乐人依然保有自嘲的傲骨与不灭的热情**。李荣浩以此纪念自己高中时在南京组建乐队的青春岁月，将“乐团”定义为一种**精神归属**，而非一个职业标签。

**视窗叙事**

这首歌的视窗是一间**闷热、逼仄的乐团排练室**。我们随着主唱的视角，看到乐队的日常：吉他手漂亮的女朋友、键盘手潇洒地要唱一段、几个人凑在一起写歌词。这些琐碎又生动的细节，构成了一个真实的、充满青春气味的封闭空间。歌曲的叙事全程没离开过这间排练室，它既是物理空间，也是音乐人整个青春与梦想的容器。

**情绪势能**

这首歌的能量是**在“自嘲的下沉”与“骄傲的上扬”之间循环摆动**的。歌曲开篇用具体的画面和细节进行平缓叙述，带着些许自嘲。副歌的“wu”是能量的第一次释放，但随即被“我们的歌没有人喜欢”拉回现实，形成“自嘲-骄傲-自嘲”的循环。这种循环在结尾被打破，当歌词从“没有人喜欢”变为“有些人喜欢”、“是人都喜欢”甚至“成为了自传”时，能量终于挣脱了怀疑，完成了向自我肯定的上扬。

#### 歌曲风格与同类型参考

**风格定位**

《乐团》是一首融合了**独立摇滚（Indie Rock）** 与**放克（Funk）** 元素的作品。编曲将带有Funk味道的贝斯线注入到摇滚的躯干中，吉他与贝斯在左右声道轻点开场，鼓点扎实，充满复古摇滚的质感。歌曲在3分25秒的时长内，呈现出“数学摇滚的机巧动听”，是一首典型的Band Sound作品。

**同风格歌曲参考**

- **草东没有派对《山海》**：《乐团》的编曲路数让人不禁想起草东没有派对，在独立摇滚的 gritty 质感和情绪宣泄上有着相似的基因。
- **李荣浩《我知道是你》**：同专辑《耳朵》中的另一首作品，同样弥漫着浓厚的独立摇滚氛围，在编曲的起承转合与爆发力上堪称全专之最。
- **李荣浩《嗯》**：同样是李荣浩在风格上突破的作品，以重型、复古的摇滚节奏表达叛逆态度，在摇滚能量上一脉相承。

Intro - A1 - A2 - B1 - Inter - A3 - B1 - B2

#### 逐句歌词解析

| :-------- | :-------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **主歌1** | 吉他手女朋友 又漂亮又很瘦 / 键盘手回头潇洒的 / 对我说 对我说 / 他来唱一段                     | 以乐队成员的外部特征和互动开场，瞬间将听众拉入排练室的闲聊氛围。通过“吉他手”、“键盘手”等具体角色，描绘出乐团成员之间真实、随性的相处日常。                                             |
| **主歌2** | 排练室的闷热 闷出好几首歌 / 都以为会红会火的那种歌 / 呵呵呵                                   | “闷热”既是物理环境，也象征梦想被压抑的状态。“闷出好几首歌”是苦中作乐的自嘲。“都以为会红会火”是每个乐手都曾有过的确信，而“呵呵呵”的笑声则瞬间消解了这份确信的严肃性，是自嘲，也是苦笑。 |
| **副歌1** | wu 我们的歌没有人喜欢 / wu 我们的青春留在乐团                                                 | 副歌的“wu”是一种无需歌词的、纯粹的情绪宣泄。“没有人喜欢”是残酷的现实，但“青春留在乐团”则将现实升华为一种无悔的价值肯定——即便不被认可，这段时光也定义了“我们”。                         |
| **主歌3** | 写歌词的时候 几个人一起凑 / 押不上韵的就当做是风格 / 呵呵呵                                   | 从排练场景转向创作场景。“几个人一起凑”写出了乐队创作的集体与随性。“押不上韵的就当做是风格”是音乐人面对不完美时的洒脱与机智，将“凑合”转化为一种独特的“风格”。                           |
| **副歌2** | wu 我们的歌没有人喜欢 / wu 我们的青春留在乐团                                                 | 副歌的重复，强化了“不被喜欢”的苦涩与“青春无悔”的骄傲之间形成的张力，是歌曲情绪循环的核心。                                                                                             |
| **副歌3** | wu 我们的歌有些人喜欢 / wu 我们的青春留在乐团 / wu 我们的歌是人都喜欢 / wu 我们的青春留在乐团 | 歌词在此处发生关键转折。“有些人喜欢”是希望的微光，随即膨胀为“是人都喜欢”的夸张想象。这是从被现实打压到用幻想进行自我补偿的过程。                                                       |
| **尾声**  | wu 我们的歌成为了自传 / wu 我们的名字是…                                                      | 歌曲的最终升华。“歌”不再只是作品，而成为了记录他们人生的“自传”。“我们的名字是…”以一个未完成的问句结尾——名字是什么并不重要，因为“乐团”本身，就是他们共同的名字。                        |
