### 《张家明和婉君》

#### 创作主题与动机

**动机母题**

日常瞬间 vs. 永恒定格。《张家明和婉君》的母题不在于“爱情故事”本身，而在于**如何用一首歌的长度，把恋爱中最普通、最琐碎的日常瞬间，变成可以被反复回味的永恒画面**。吹头发、喝水、背你过河、卷裤管——这些动作本身没有任何戏剧性，但它们在被唱出来的那一刻被定格了。而“地久天长就会变成对方”是全曲最核心的判断——不是“我们会永远在一起”，是“在一起久了，我们就变成了对方”。这不是山盟海誓，是比山盟海誓更具体的亲密：你的习惯变成了我的习惯，你的样子变成了我的样子。

李荣浩酷爱港片，这首歌的复古灵感源于1992年香港电影《家有喜事》里的家明表哥和婉君表妹。他将“张家明”和“婉君”想象成90年代港片中的角色，也可能是家里附近某位亲切的老邻居。歌名采用这两个具有时代特征的常见中文名组合，既强化了歌曲的叙事代入感，也通过对比式命名引发听众对角色关系的联想。这首歌是李荣浩为纪念出道五周年（2013年9月17日发行首张专辑《模特》）而特别创作的“心动单曲”。

**视窗叙事**

这首歌的视窗是一个**90年代港片的胶片镜头——柔光、暖色调、慢动作**。“头发吹干/扎一道弯”“水喝一半/要我帮你喝完”是第一组画面——私人空间里的亲密动作，旁观者看不到，但镜头捕捉到了。“篱笆红杉/背你去看/黄昏河畔/手留给你挽”把视窗从室内拉到了室外——黄昏、河畔、篱笆，像一部复古爱情电影的外景。

这个视窗的特殊之处在于：**镜头同时捕捉了“男孩的视角”和“女孩的视角”**。“男孩呆呆的想了一下/啥也不懂”是男孩的内心独白——他在发呆，他不知道自己在想什么，他只是感受着“抱的紧紧的动作”。“女孩眨眨眼笑了一下/让人心疼”是女孩的反应——她在笑，但“让人心疼”这个判断来自男孩。两个视角交替出现，像是在说：我们都在看对方，但我们各自看到的是不一样的东西。结尾“男孩在沙发赖着/女孩翻书走过”是最后一个画面——没有对话，没有互动，只是一个在沙发上赖着，一个翻着书走过。这个画面没有任何“情节”，但它就是整首歌的最终落点：**在一起，就是在一起待着**。

**情绪势能**

这首歌的能量是**持续的、微微上扬的暖流**。前奏以“节奏鲜明的打击乐和吉他”切入，定下了轻快、明媚的基调。主歌是叙述式的、带着画面感的——“头发吹干”“水喝一半”“背你去看”“手留给你挽”像一组连贯的镜头，能量平稳地流动，没有起伏。预副歌“傻笑/是你对我多好/我知道”是能量第一次微微上扬——从描述画面转向了确认感受。副歌“男孩呆呆的想了一下/啥也不懂/感受那抱的紧紧的动作”是能量最集中的释放——但释放的方式不是呐喊，是“呆呆的想了一下”的停滞。整首歌的能量从头到尾都维持在一个温暖、明媚的刻度上，像一部90年代港片的配乐，你不需要被它打动，你只需要被它包围。

#### 歌曲风格与同类型参考

**风格定位**

《张家明和婉君》是一首**中板轻快情歌**，被形容为“充满清新风味的粉红色泡泡情歌”。编曲以**节奏鲜明的打击乐**和**吉他**为主导，营造出90年代港片的复古质感。李荣浩独立完成了词曲、编曲、制作、吉他、贝斯、和声编写、录音、混音等绝大部分工作。这首歌是李荣浩“全新复古概念系列”的第五部作品。整首歌的听觉质感是“温暖梦幻”的——它不是让你哭的歌，是让你嘴角不自觉上扬的歌。有乐评形容这首歌“粉红又明媚”，是李荣浩“为数不多的甜美的歌”。

**同风格歌曲参考**

- **李荣浩《在一起嘛好不好》**：同样以轻快的节奏和日常化的细节写恋爱中的甜蜜时刻，同样用简单的吉他编曲承载温暖的情感。
- **李荣浩《我看着你的时候》**：同样写青春期的甜蜜爱恋，同样以“羞涩”和“直白”之间的张力为核心，同样用轻快的旋律营造明媚的听觉质感。
- **李荣浩《哎呀》**：同样写“停留在此刻的幸福”，同样用日常化的细节和简单的编曲构建私密的浪漫空间。

| **主歌1**        | 头发吹干 扎一道弯 / 水喝一半 要我帮你喝完                                                                      | 开篇是两个极其私密的日常画面。“头发吹干扎一道弯”是帮对方吹头发、扎头发的动作——只有亲密到一定程度的人才会做。“水喝一半要我帮你喝完”是分享一杯水——不嫌弃，不客气，像呼吸一样自然。这两句没有任何“爱”字，但每一个动作都是爱的证据。                                                                                       |
| **主歌2**        | 篱笆红杉 背你去看 / 黄昏河畔 手留给你挽                                                                        | 从室内走向室外。“篱笆红杉”是乡村风景，“背你去看”是一个身体性的动作——不是并肩走，是背着走。“黄昏河畔”是时间（黄昏）和地点（河畔）的并置，“手留给你挽”是把手留给对方挽。四个短句拼凑出一幅完整的画面：一个黄昏，一条河，一对恋人，一个背着一个，手挽着手。                                                               |
| **预副歌**       | 傻笑 是你对我多好 我知道 / 是你让我知道 那种好 / 是有过去可聊 / 是你睡着拉着我衣角                             | “傻笑”是男孩被甜到的表情。“是你对我多好/我知道”——“我”知道“你”对“我”好，不是后知后觉，是当时就知道。“是你让我知道那种好”是第一个判断——这段关系让“我”第一次知道“好”是什么。“是有过去可聊”是第二个判断——好的关系不只是有未来，是可以一起聊过去。“是你睡着拉着我衣角”是第三个画面——睡着之后无意识的动作，是最真实的依赖。  |
| **副歌**         | 男孩呆呆的想了一下 啥也不懂 / 感受 那抱的紧紧的动作 / 女孩眨眨眼笑了一下 让人心疼 / 还说 昨天做的梦里有我 有我 | “男孩呆呆的想了一下啥也不懂”——他在发呆，他不知道自己在想什么，他只是“感受着那抱的紧紧的动作”。“啥也不懂”是男孩的自白——不懂爱是什么，不懂怎么表达，只是本能地抱紧。“女孩眨眨眼笑了一下让人心疼”——她的笑不是开心的笑，是“让人心疼”的笑。“还说昨天做的梦里有我”是整首歌最甜的一句——她在梦里见到了你，然后她把梦告诉了你。 |
| **主歌3**        | 雨刚停下 泥土清香 / 地久天长 就会变成对方                                                                      | “雨刚停下泥土清香”是雨后的嗅觉记忆——清新、湿润、具体。“地久天长就会变成对方”是全曲最核心的判断——不是“我们会永远在一起”，是“在一起久了，我们就变成了对方”。你的习惯、你的表情、你的语气，慢慢变成了我的。                                                                                                               |
| **主歌4**        | 牛仔布料的情侣衫 / 给我裤管 卷两褶好看                                                                         | 穿情侣衫是恋爱中最“俗”的事，但“给我裤管卷两褶好看”把“俗”变成了“私”——不只是穿一样的衣服，是帮你把裤管卷好。“卷两褶”是一个具体的数字，说明这个动作做过很多次，已经熟练到知道卷几褶最好看。                                                                                                                               |
| **副歌（重复）** | （重复副歌段落）                                                                                               | 副歌在歌曲后半段完整重复。“有我”在结尾处重复了多次，像在反复确认同一个事实：她在梦里见到了我，她告诉我了，这件事是真的。“有我/有我”的重复本身就是这首歌的叙事方式——同样的画面、同样的“啥也不懂”、同样的“让人心疼”、同样的“梦里有我”，翻来覆去地确认，像是在说：这一切都是真的。                                        |
| **结尾**         | 男孩在沙发赖着 女孩翻书走过                                                                                    | 最后一句是整首歌的收束。没有对话，没有互动，只是一个在沙发上赖着，一个翻着书走过。“赖着”是放松的、不设防的状态，“翻书走过”是安静的、日常的动作。这个画面没有任何“情节”，但它就是整首歌的最终落点——**在一起，就是在一起待着**。不需要说话，不需要做什么，你在我旁边，我在你旁边，这就够了。                             |
