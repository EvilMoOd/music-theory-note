### 《耳朵》

#### 创作主题与动机

**动机母题**

“耳朵”的灵敏 vs. “心房”的空荡。《耳朵》的母题不在于思念本身，而在于**失去之后，感官如何背叛你的理智，强行将你拉回过去**。你不想听，但耳朵不听话；你不想哭，但眼睛湿透了。整首歌的张力就在这组矛盾里：**你越是想封闭自己，感官越是不受控制地指向那个已经离开的人**。

这首歌是李荣浩自出道以来，**首次在个人专辑中收录由他人创作的歌曲**——词作者是已故的80后“性情词人文炅”。李荣浩在2017年听到这首歌的小样时就被歌词打动，得知词作者英年早逝后，他决定尊重原作者的意志，放弃改词的念头，并将“耳朵”定为专辑名称。

**视窗叙事**

这首歌的视窗是一个**听觉被无限放大、视觉被主动屏蔽的密闭空间**。“谁的脚步近了/谁的脚步远了/我都竖起耳朵”是第一组声音——你在等一个脚步声，它可能来了，可能没来，你无法确定。“听着楼道里还是空空荡荡的”是声音的落空——你听到了“空”，听到了“没有”。

李荣浩在制作这首歌时，脑海里的视觉概念是“闭上眼睛，只剩下耳朵”。MV中，李荣浩和演员们全部蒙上双眼，创造一个完全没有视觉的世界，以听觉来感受生活的所有细节。这个视窗全程不依赖任何视觉信息——楼道是听出来的，心房是听出来的，连“茶饭不思呆呆地凝望着”这个画面，也是在一个“闭着眼睛”的状态下被感知的。

**情绪势能**

这首歌的能量是**从期待到落空、从感官的亢奋到情绪的溃散**的下行弧线。开篇“谁的脚步近了/谁的脚步远了”是听觉高度警觉的状态——你在期待一个声音，能量是绷紧的。但“听着楼道里还是空空荡荡的”把期待击碎，能量开始下坠。“总是闭着耳朵/直到心房里变得空空荡荡的”是主动封闭与被动空洞的交替——你试图关上耳朵，但心房反而空了。

副歌“只有耳朵不听话了”是能量最低点——你控制不了自己的耳朵，也控制不了自己的情绪。“烂俗桥段眼睛却湿透了”是最诚实的崩溃——明知道是“烂俗桥段”，眼泪还是下来了。编曲中加入了长号、小号、萨克斯风，结合了爵士的节奏风格，用复古的、温暖的器乐音色，去包裹一段清冷的内核。

#### 歌曲风格与同类型参考

**风格定位**

《耳朵》是一首融合了**爵士（Jazz）与流行**元素的抒情作品。编曲由李荣浩完成，加入了**长号、小号、萨克斯风**和**弦乐**，结合了爵士的节奏风格。人声方面，李荣浩用他标志性的低沉嗓音，以近乎耳语的音量演唱，营造出一种“在耳边轻轻诉说”的私密感。整首歌时长4分58秒，被形容为“用安抚的手段来激发耳朵听更内心的声音”。有乐评指出，这首歌“仿佛就能听见人们的喜怒哀乐”，让人体会当没有了视觉所带来的冲击，“耳朵才更能‘听’见内心最柔软、脆弱的一面”。

**同风格歌曲参考**

- **李荣浩《戒烟》**：同样以日常生活中的具体意象承载一段放不下的感情，同样以“从压抑到微微释放”的唱腔推进情绪。
- **李荣浩《念念又不忘》**：同属专辑《耳朵》，同样以“被一个微小事物击穿”的结构写记忆的顽固，同样以复古的编曲质感包裹清冷的内核。
- **陈奕迅《好久不见》**：同样以低沉克制的声线和简约的编曲，写一个人在失去之后平静地回望过去的状态。

Intro-A-B-A-B-Inter-B-Outro

#### 逐句歌词解析

| :-------- | :--------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **主歌1** | 谁的脚步近了 / 谁的脚步远了 / 我都竖起耳朵 / 听着楼道里还是 / 空空荡荡的                 | 开篇是一组声音的追踪——脚步声“近了”又“远了”，你在判断方向，但无法确定。“竖起耳朵”是一个警觉的动作，像动物听到动静时的本能反应。但“听着楼道里还是空空荡荡的”把期待彻底击碎——你听到了“空”，听到了“没有”。                                         |
| **主歌2** | 我没听你倾诉 / 没驱赶你孤独 / 总是闭着耳朵 / 直到心房里变得 / 空空荡荡的                 | 这是整首歌唯一的倒叙——它揭示了“为什么你会离开”。“没听你倾诉”是当时的选择，“总是闭着耳朵”是重复的行为模式。而当“你”走了之后，“心房里变得空空荡荡的”。你在的时候我闭上了耳朵，你走了之后我的心空了。                                             |
| **副歌1** | 所有的感官都要变迟钝 / 茶饭不思 呆呆地凝望着 / 只有耳朵不听话了 / 非要我听那首最爱的老歌 | “所有的感官都要变迟钝”是自我保护的本能——不想吃、不想动、不想感知任何东西。“只有耳朵不听话了”是整首歌的题眼——你想关掉所有感官，但耳朵不受控制。“最爱的老歌”是你们一起听过的歌，耳朵在强迫你面对它。                                             |
| **副歌2** | 所有的情绪都要变脆弱 / 烂俗桥段 眼睛却湿透了 / 左右耳朵也埋怨着 / 最近好像少了些什么     | “烂俗桥段”是自嘲——明明知道这只是俗套的剧情，眼泪还是下来了。“左右耳朵也埋怨着”把耳朵拟人化了——耳朵在埋怨你，因为它被迫反复听那首老歌。“最近好像少了些什么”是整首歌最轻的一句，也是最重的一句——你不敢说“少了你”，你只说“少了些什么”。           |
| **重复**  | （重复主歌1、主歌2、副歌1、副歌2）                                                       | 歌曲后半段完整重复了前面的所有段落。重复本身就是这首歌的叙事方式——**同样的脚步声、同样的空荡、同样的“不听话”、同样的“少了些什么”，翻来覆去地出现，像一个人在同一个问题上反复绕圈，绕了很多遍，还是绕不出去。**                                 |
| **结尾**  | 最近少一个人 好寂寞                                                                      | 最后一句把“少了些什么”变成了“少一个人好寂寞”。前面所有的“空空荡荡”“变迟钝”“不听话”“湿透了”都在为这一句铺路。最后四个字“好寂寞”落在了一个没有任何修饰的位置上——不是“有点寂寞”，不是“我觉得寂寞”，就是“好寂寞”。歌结束了，但“好寂寞”还在空气里。 |
